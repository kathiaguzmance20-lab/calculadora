# Calculadora

Calculadora web adaptable a móvil y escritorio, hecha con HTML, CSS y JavaScript sin dependencias.

## Funciones

- Suma, resta, multiplicación y división
- Porcentajes, cambio de signo y borrado
- Tema claro y oscuro
- Entrada desde teclado o pantalla
- Diseño adaptable

## Uso

Abre `index.html` en un navegador.

### Teclado

Usa los números y `+`, `-`, `*`, `/`. Pulsa `Enter` o `=` para calcular, `Backspace` para borrar y `Escape` para limpiar.
